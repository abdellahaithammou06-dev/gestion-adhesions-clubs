# Gestion des adhésions aux clubs étudiants
Application JEE (Servlets, JSP, Hibernate, MySQL) - ENSA Agadir.

## Installation
1. Créer la base MySQL `gestion_adhesions` et l'utilisateur `adhesions`.
2. Copier `src/main/resources/hibernate.cfg.example.xml` vers `hibernate.cfg.xml` et saisir le mot de passe.
3. `./scripts/deploy.sh` puis ouvrir http://localhost:8080/adhesions/
